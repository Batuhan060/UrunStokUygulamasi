 Ürün ve Stok Takibi

Bu uygulamada ürün ekleyebilir, stok miktarını artırıp azaltabilir ve ürün silebilirsin. Ürünler tarayıcıda saklanır sayfayı yenileyince kaybolmaz.

 Nasıl açılır?

1. dosya.html, gorunum.css ve uygulama.js dosyalarını aynı klasörde tutun.
2. dosya.html dosyasına çift tıklayın.
3. Ürün adı ile sıfır veya daha büyük sayı stok miktarını yazıp Ürün ekle düğmesine basın.
4. (+) stoğu artırır, (-) azaltır, Sil ürünü kaldırır.

 İnternetsiz çalışır.
